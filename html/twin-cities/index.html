Using This Site

Upcoming movies for the theaters we track are shown to the right. If you'd like a calendar feed to follow in Google Calendar or Apple Calendar, you can copy the URL from the pulldown menu "Calendar Feeds". We provide both one consolidated feed and per-theater feeds. If you prefer an RSS feed, use the "RSS Feed" link.

Theaters

Trylon Cinema

Trylon Cinema is a microcinema whose mission is to cultivate community by screening classic, contemporary, independent, and foreign films at Trylon Cinema in South Minneapolis and other venues throughout the Twin Cities.

The Main Cinema

The MSP Film Society brings the best international and independent films to Minnesota audiences via, among other things, daily programming 365 days a year on all five screens at The Main Cinema.

About This Site

I'm horrible at keeping track of movies I want to see. I subscribe to all the local cinema newsletters but that's not enough for me. Thus, I wrote some code to scrape various cinema web sites and generate a calendar. It seemed as though this might be useful to other people so now there's a Web site.

The original version of this site was created for Seattle and there's also a version for Dublin.
